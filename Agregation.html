Couplages leçons et développements


Voici un document avec mes leçons, mes couplages choisis le jour J ainsi que la liste de mes développements.

Pour chaque développement, j'indique les leçons correspondantes, les références utilisées et l'énoncé, puis pour certains j'en donne une preuve plus ou moins détaillée. J'ai décidé de ne rédiger que certains développements, soit pour compléter les références citées, soit pour ajouter une petite touche personnelle, soit parce qu'il s'agit d'un développement que j'aime bien. Quelques références et liens utiles

  • Analyse de Fourier dans les espaces fonctionnels, El Amrani : très bonne référence pour la convolution, la transformation de Fourier ainsi que les séries de Fourier.
  • Analyse pour l'agrégation : 40 développements, Bernis : pas mal de développements qui se recasent bien et qui sont bien expliqués.
  • Cours d'analyse fonctionnelle, Li : très bien pour les espaces de Hilbert et pour les résultats autour du théorème de Baire.
  • Introduction aux variétés différentielles, Lafontaine : pour la géométrie différentielle.
  • Analyse, Gourdon / Petit guide du calcul différentiel, Rouvière : des classiques que j'ai utilisés dans beaucoup de leçons.
  • Théorie de Galois, Gozard : très bonne référence pour compléter Cours d'Algèbre de Perrin, notamment pour les polynômes et les extensions de corps.
  • Algèbre linéaire : réduction des endomorphismes, Mansuy-Mneimné : petit livre mais qui recouvre quasiment toute la réduction.
  • Les contre-exemples en mathématiques, Hauchecorne : tout est dans le titre.


Pour les probabilités :
  • Probabilités pour les non-probabilistes, Appel : très bonne référence à mon avis, traite de beaucoup de choses et de manière progressive.
  • Promenade aléatoire, Benaïm : pour les martingales et les chaînes de Markov.
  • De l'intégration aux probabilités, Garet-Kurtzmann.
  • Probabilités pour l'épreuve de modélisation, Chabanol : un indispensable pour l'épreuve de modélisation en option A, recouvre tout le programme.
  • Python proba stat, Vigon : pour vous aider en Python et peut vous dépanner le jour J pour votre code.
